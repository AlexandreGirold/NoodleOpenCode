# Generated architecture views

The `.mmd` files are generated from the adjacent authoritative model and views.
Run `scripts/check-mermaid.sh` from the repository root to check reproducibility.
The four PNGs are visual verification artifacts rendered
with Mermaid CLI; they are examples of automatic layout, not hand-authored layouts.

Verified with Mermaid CLI 12.0.0 (Mermaid 12.2.0). Example rendering command:

```bash
pnpm exec mmdc -i communication.mmd -o communication.png --size 2400 -b '#0f172a'
```

The CLI is optional external verification/viewing tooling, not a noodle dependency.
